ONG GEPAR — Proteção e Adoção Animal

📖 Sobre o projeto

Este projeto consiste no desenvolvimento de uma plataforma web para a ONG GEPAR (Grupo Esteiense de Proteção aos Animais de Rua), localizada em Esteio, Rio Grande do Sul.

A plataforma tem como objetivo ampliar a visibilidade dos animais disponíveis para adoção, incentivar a adoção responsável, divulgar campanhas e aproximar a comunidade do trabalho realizado pela organização.

Salvar um animal não muda o mundo inteiro, mas muda a vida dele.

🎯 Objetivos

Incentivar a adoção responsável.

Facilitar a divulgação dos animais disponíveis para adoção.

Aproximar os interessados dos responsáveis pelos animais.

Incentivar o voluntariado e as doações.

Divulgar feiras, eventos e campanhas.

Promover a conscientização sobre a proteção animal.

🔗 Arquitetura do projeto

O projeto está sendo desenvolvido em equipe, seguindo uma arquitetura Full Stack.

Front-end: React.js.

Back-end previsto: Java com Spring Boot e API REST.

Banco de dados previsto: PostgreSQL.

O front-end utiliza componentes reutilizáveis, navegação entre páginas e uma camada de serviços preparada para a futura integração com a API REST.


🤝 Sobre a ONG GEPAR

A ONG GEPAR atua na proteção, recuperação e adoção responsável de animais em situação de abandono e vulnerabilidade.

Seu trabalho contribui para a construção de uma sociedade mais consciente, solidária e comprometida com o bem-estar animal.
